HABIT TRACKER MOBILE V8

TO-DO UPDATE
- No automatic end-of-day deletion anymore.
- To-dos remain saved until you choose to delete them.
- Checked to-dos stay visible and remain checked.
- Tap a checked to-do again to mark it incomplete.
- Every to-do now has its own × delete button.
- Added Clear all for all to-dos on the currently selected date.
- Clear all asks for confirmation.
- To-dos are still tied to their original date.
- To-dos still do NOT affect:
  - habit completion
  - streaks
  - Dashboard statistics
  - Month statistics
  - habit history

GITHUB UPDATE
1. Replace the V7 files in your GitHub Pages branch with V8.
2. Commit the changes.
3. Wait for Pages deployment.
4. Open the site once in Safari with ?v=8 and refresh.
5. Reopen the Home Screen app.
